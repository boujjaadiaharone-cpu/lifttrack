# LiftTrack

Version 2 : suivi de musculation + journal de repas avec photos + hydratation.

Installation iPhone :
1. Héberger `index.html` et `manifest.json` à la racine d'un site HTTPS.
2. Ouvrir le site dans Safari.
3. Partager -> Ajouter à l'écran d'accueil.

Les données sont stockées localement sur l'appareil.
