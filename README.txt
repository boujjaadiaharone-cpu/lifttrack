LIFTTRACK — application PWA de suivi musculation

Installation iPhone:
1. Héberge le dossier sur un site HTTPS (GitHub Pages, Netlify, etc.).
2. Ouvre l'adresse dans Safari sur l'iPhone.
3. Partager -> Ajouter à l'écran d'accueil.
4. Lance LiftTrack depuis l'icône.

Les données sont stockées localement dans le navigateur de l'appareil.
